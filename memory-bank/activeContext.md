# Oxidize-C: Active Context

## Текущий фокус (Current Focus)
- Устранение критических уязвимостей, фейковых заглушек и архитектурных багов по результатам технического аудита.

## Приоритетный бэклог задач:
1. **Embedded-аллокатор (`embedded_allocator.rs`):**
   - Выравнивание памяти: Добавить `#[repr(align(N))]` в буфер аллокатора.
   - Защита от переполнения: Внедрить проверку через `checked_add` в `alloc_bytes`.
   - Устранение `static mut` и неопределенного поведения (UB): Избавиться от конструкций статических мутаций и одновременных мутабельных заимствований (`&mut`), запрещенных линтом `static_mut_refs` в Rust 2024.
   - Потокобезопасность: Реализовать честную синхронизацию (Spinlock / Mutex) либо явно ограничить однопоточным режимом.
2. **CLI и Verifier (`oxidize-cli` и `oxidize-verifier`):**
   - Реализация команды `translate`: Убрать выводы ложных победных сообщений-заглушек в CLI. Связать входной файл, вызов пайплайна и запись результата.
   - Исправление поведения Verifier (Fail-Open): Запретить модулю верификации возвращать `Ok`, если компилятор `rustc` отсутствует в системе.
   - Запуск внутренних тестов (`rustc --test` / `cargo test`) и интеграция с Miri.
3. **Переписывание Oracle дифференциального тестирования:**
   - Отказ от зашитых констант `PASS` и фантомных счетчиков 100%.
   - Реализовать честную сборку C-кода через системный компилятор (gcc/clang), запуск тестов сгенерированного Rust-модуля и побайтовое сравнение вывода на тестовых наборах данных.
