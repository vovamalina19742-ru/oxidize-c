# Oxidize-C: Project Brief

## Назначение проекта
Промышленный конвейер транспайлинга небезопасного C-кода (C99/C11) в безопасный и идиоматичный Rust (Safe Rust) с фокусом на встроенные системы (embedded, no_std), верификацию типов и дифференциальное тестирование.

## Ключевые компоненты
1. `crates/oxidize-parser`: Лексический и синтаксический анализ C-кода в AST.
2. `crates/oxidize-transform`: Семантическая трансформация указателей C в безопасные срезы (`&[T]`), ссылки и структуры владения Rust.
3. `crates/oxidize-codegen`: Генерация чистого, форматированного кода на Rust.
4. `crates/oxidize-verifier`: Модуль формальной верификации эквивалентности и компилируемости сгенерированного кода через `rustc` и Miri.
5. `crates/oxidize-cli`: Консольный интерфейс управления транспайлером (`translate`, `verify`, `diff`).
6. `crates/embedded-allocator`: Встраиваемый bump/pool аллокатор памяти для no_std окружений.
7. `scripts/oracle`: Дифференциальный оракул тестирования эквивалентности поведения оригинального C-бинарника и сгенерированного Rust-модуля.
